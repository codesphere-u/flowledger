FlowLedger Documentation

Pan-African interledger engine, double-entry accounting, and ISO 20022 reconciliation.

Install Double-Entry Mobile Money & FX ISO 20022 MCP & Aegis G6

1. Installation & Quick Audit

git clone https://github.com/codesphere-u/flowledger.git
cd flowledger
pip install -e ".[dev]"
flowledger demo
flowledger verify-invariants

2. Integer Minor-Unit Double-Entry

Every JournalEntry enforces integer minor units across 12 currencies and validates Sum(Debits) == Sum(Credits) before appending to the SHA-256 hash chain and SQLite WAL store.

3. Pan-African Rails & Cross-Border FX

Offline payload builders and parsers model Safaricom M-Pesa Daraja 2.0 (STK Push, C2B, B2C), MTN MoMo, Airtel Money, Wave, Orange Money, Tigo Pesa, and rate-locked FX quotes.

4. ISO 20022 & 3-Way Reconciliation

Generate and parse pacs.008, pacs.002, and camt.053 XML statements and export CSV reconciliation and exception reports cleanly.

5. MCP Server & Nexus Aegis G6

flowledger mcp
flowledger export-aegis
