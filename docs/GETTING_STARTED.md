# Getting Started with FlowLedger

`flowledger` (`v2.1.0`) is an immutable integer minor-unit double-entry ledger, multi-rail African payment orchestrator, and 3-way reconciliation engine.

## Installation & Verification

```bash
git clone https://github.com/codesphere-u/flowledger.git
cd flowledger
pip install -e ".[dev]"
flowledger demo
flowledger verify-invariants
```
